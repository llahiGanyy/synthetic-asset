# Synthetic Asset Contract

A contract for creating and managing synthetic tokens that track the value of
external assets using collateral and on-chain pricing references.

## Key Functions
- `mint-synth` — Create synthetic assets using collateral
- `burn-synth` — Redeem and destroy synthetic tokens
- `get-synth-balance` — Retrieve user synthetic asset balance
- `set-collateral-ratio` — Configure required collateralization level
- `get-synth-info` — View synthetic asset parameters and status

Designed for DeFi protocols, derivatives platforms, and synthetic markets.
